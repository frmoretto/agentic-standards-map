W3C Web Payment Security Interest Group

W3Cvenuecontext entry

Verified 2026-10-03. Status as of 2026-10-03. All entries.

Status

Chartered 2025-04-01 to 2027-03-31 (shortname securepay); the draft Agentic Web charter lists the IG for "agentic payments".

Relevance

Mission: "enhance the security and interoperability of various Web payments technologies"; a W3C staff member expected the e-commerce workshop to identify future workstreams for this group (webai-roadmap#45, 2026-06-11).
