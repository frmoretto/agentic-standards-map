FIDO Alliance agentic authentication and payments work

Industrywork-itemcontext entry

Verified 2026-10-19. Status as of 2026-10-14. All entries.

Seams: S4

Status

Announced 2026-04-28: an Agentic Authentication Technical Working Group, and work in the Payments Technical Working Group starting from Google (AP2) and Mastercard (Verifiable Intent) contributions.

Relevance

The release says the Payments Technical Working Group is "chaired by members from Mastercard and Visa"; it says contributed; Google's announcement of the same day says "We're donating Agent Payments Protocol to the FIDO Alliance", and the AP2 repository says its core specification has been donated to FIDO. For the Agentic Authentication Technical Working Group the release says it is "chaired by members from CVS Health, Google and OpenAI and vice-chaired by members from Amazon, Google and Okta" (read in a browser on 2026-10-14); it names companies, not persons.

Committed next

None declared in the sources read.
