W3C Browser Testing and Tools Working Group

W3Cchartercontext entry

Verified 2026-10-23. Status as of 2026-10-23. All entries.

Status

The Browser Testing and Tools Working Group has a new charter: the W3C charters page of the group lists it as "Chartered under the Patent Policy 2025 from 2026-10-21 until 2028-10-20 (active)", and the charter document gives "Start date 20 October 2026" and "End date 20 October 2028"; the activity page of the group lists a Call for Participation on 2026-10-21, with "Participants had to rejoin under this charter." Chair: David Burns (W3C Invited Experts) (read 2026-10-23). The draft of this charter had been updated by pull request #882 on w3c/charter-drafts, "Update charter-wg-btt.html", merged on 2026-10-07 at 17:24 UTC.

Relevance

The scope of the charter "includes protocols and APIs for automation of web browsers, for purposes including automated testing of web applications, and agentic browsing where a user interacts with their browser through an automation API."; the draft change of pull request #882, opened by tantek, said it "Updates to broaden Motivation and Background, Scope sections to include end users and agentic browsing use-cases."

Committed next
