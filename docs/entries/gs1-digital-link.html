GS1 Digital Link Standard, URI Syntax 1.7.0

GS1specificationcontext entry

Verified 2026-11-09. Status as of 2026-10-13. All entries.

Seams: S2

Status

Release 1.7.0 ratified August 2026; the archive on ref.gs1.org lists "Published 7 August 2026".

Relevance

The syntax "distinguishes between primary identification keys that express simple GS1 identifiers, such as GTIN and GLN" and key qualifiers and attributes; a GS1 Digital Link URI "is a particular form of URL". The standard says applications "SHALL NOT assume" that a URL in this syntax points to a resolver, and names a Resolver Description File as one test (section 2).

Committed next

None declared in the sources read.
