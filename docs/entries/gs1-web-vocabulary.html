GS1 Web Vocabulary

GS1specificationcontext entry

Verified 2026-11-09. Status as of 2026-11-09. All entries.

Seams: S2

Status

Version 1.18: the ontology carries owl:versionInfo "1.18" and dct:modified 2026-06-01, and the archive on ref.gs1.org lists version 1.18.0 published 2026-06-01. A ratification label with a date for 1.18 is not found in the pages read. The change log, read 2026-11-09, gives no dates, and its newest entry is 1.17.0, so it does not yet list 1.18.

Relevance

The vocabulary "is designed as an extension to schema.org" and defines parties and a product offer; gs1:Product, gs1:Offer and gs1:Organization carry skos:exactMatch mappings to the schema.org terms of the same name, and gs1:gtin to schema:gtin14. It also holds the link types used in GS1 Digital Link, under the namespace https://ref.gs1.org/voc/ (opens in a new tab), with data in JSON-LD and Turtle and JSON-LD context files that the landing page labels "provisional".

Committed next

None declared in the sources read.
