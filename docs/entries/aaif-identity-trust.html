AAIF Identity and Trust group, issue #13 and the agentrust-io integrations (TRACE)

AAIFwork-itemcontext entry

Verified 2026-11-02. Status as of 2026-10-19. All entries.

Status

Issue #13 of aaif/wg-identity-and-trust compares how MintID and Proofable record authority at the point where an agent action is dispatched; it was open with 18 comments on 2026-10-19, the last of that day. The shared runner proposed for it, pull request #288 of agentrust-io/integrations (head 74fc43c), was merged on 2026-10-13 at 18:00 UTC (merge commit 5f9b48e) by the project lead of TRACE, who had approved it on 2026-10-12, and its tracking issue #287 was closed the same minute. TRACE, the format those integrations cite, is a specification (v0.2, Developer Preview) with a released reference package (agentrust-trace 0.11.0, 2026-09-25). The independent run: on issue #13, a participant from Bitgrit ("Role: independent operator; Bitgrit submits no implementation. Disclosure: Bitgrit develops DID/VC identity infrastructure.") wrote on 2026-10-14 that "Bitgrit is the executing partner for the independent reproduction", with an active start date of 2026-10-13, and on 2026-10-18 that Round 1 was set to the baseline frozen on 2026-10-13 "to meet the October 30 deadline". On 2026-10-19 the same participant posted an "Independent Operator Round 1 Final Comparison Record" for four cases, all with the implementation "MintID / agent-evidence-observer", run against the MintID tag public-v2026-10-17.1; the record states a DENY dispatch decision in each of the four cases. These results are the operator's own statement; the archive the record links was not downloaded and nothing in it was checked here. The group's Reference Architecture sub-group has a working draft, "Agent Identity Primitives" (Draft, version 0.1, dated 2026-08-27), in a Google Doc readable without a login (read 2026-10-13 and 2026-10-19). Its scope clause reads "The following are out of scope: authorization models (what an agent is permitted to do), evidence, reputation, and security controls or threat modeling.", and its section 3.4 (Delegation) reads "This section is under active discussion." Comments in the document propose changes that are not yet in the text; they are not quoted here. Commerce, merchant, seller and purchase: not found in the document text (2026-10-19). Messages of the group's list after message 48: not read (the archive requires JavaScript and its rules ask for a licence for automated AI access).

Relevance

The group's README says "This working group meets every Thursday, alternating between 6:30AM and 9:00AM USA Pacific Time." and points to a public mailing list on lists.aaif.io; the archive of that list was not read, and six messages of it (numbers 40 and 44 to 48, 2026-10-06 to 2026-10-08) were read by the author on 2026-10-09.

Proofable (proofable/docs): an earlier evidence packet (commits 3a45f02 to 4ceb58b, 2026-10-06 to 2026-10-08) had manifest digests computed over CRLF bytes, as its author stated on 2026-10-07; the packet frozen at commit 9851059 (2026-10-08) matches its SHA256SUMS (recomputed on 2026-10-13), and its author lists the limit "Author-operated (SELF); no independent witness." MintID publishes tags on GitLab (17, from public-v2026-10-05.5 to public-v2026-10-18.1, read 2026-10-19) and a CHANGELOG.md at the root of the tagged tree, present from public-v2026-10-06, which opens "What changed for users of MintID in each public release"; no tag links to a release object.

List messages: a participant from MintID wrote on 2026-10-08 that "From public-v2026-10-08.1 a 5xx is recorded as a service interruption, never as a decision, and the run completes"; a participant from ALIGN, an organisation preparing an independent run, wrote that ALIGN "will pin public-v2026-10-08.1 or later" and "We will confirm the start date on October 15."; a participant who submitted the runner wrote on 2026-10-08 that results are recorded "as operator-reported until independently reproduced". The runner (issue #287, pull request #288) says "This is a shared evidence-appraisal runner, not a comparative certification." and "No Verified tier or conformance level is requested."; the test counts given at different heads (27 in the pull request, 28, 34) are declared by the sources and not reconciled here.

The README of agentrust-io/integrations defines two tiers, Community ("We do not run your code") and Verified, and says the tier "is set by maintainers, never self-declared". TRACE (agentrust-io/trace-spec): "Developer Preview. Launched at Confidential Computing Summit, 23 June 2026. Spec v0.2 is current."; the specification text is under the Community Specification License 1.0 and the code under Apache 2.0; the project lead listed in MAINTAINERS.md is Imran Siddique (AgenTrust-io).
