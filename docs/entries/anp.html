Agent Network Protocol (ANP)

Independentspecificationcore entry

Verified 2026-10-16. Status as of 2026-10-16. All entries.

Status

Specification set ANP 1.2, GitHub release v1.2 of 2026-09-24 (v1.1 of 2026-06-27, 1.0 of 2025-05-19); the README marks ANP-02, ANP-03, ANP-04, ANP-07 and ANP-08 "Released v1.2", the Messaging 1.2 catalog as published with profile P6 "candidate", and ANP-05, ANP-06 and ANP-10 as drafts. The release notes say "Publication of specifications does not mean implementations already support ANP 1.2".

Relevance

ANP-08 defines active discovery at https://{domain}/.well-known/agent-descriptions (opens in a new tab) and passive registration with search agents; agent-descriptions is not found in the IANA well-known URI registry (copy updated 2026-10-07, read 2026-10-14). ANP-07 describes Agent Description documents and lists among its aims "Defining core vocabularies for agent basic information, products, services, interfaces, etc.". ANP-10 is "an ANP application-layer adaptation of the Agent Payment Protocol (AP2)" and says "its presence does not establish stable interoperability, implementation conformance, or production readiness". The protocol draft of the W3C AI Agent Protocol Community Group uses the same discovery path and lists as editor Gaowei Chang, "ANP Open Source Community".

Committed next

  • README roadmap item, open: "Complete the registered MLS ExtensionType release gate for stable P6 v2." (undated) [maintainer or chair statement] https://github.com/agent-network-protocol/AgentNetworkProtocol/blob/main/README.md (opens in a new tab)

Boundary

The v1.2 release notes: "This is a documentation release: it does not change SDK, service, or product implementations, and it does not authorize public capability advertisement."
