UN Transparency Protocol, Identity Resolver

UN/CEFACTspecificationcore entry

Verified 2026-10-13. Status as of 2026-10-13. All entries.

Seams: S2

Status

Latest stable version 0.7.0 (GitLab tag of 2026-05-04); the 0.7.0 page says the team "expects to release UNTP version 1.0", without a date.

Relevance

The Resolver Workflow section lists, among "some common conditions that a link resolver service SHOULD manage consistently", "When there is no data for the requested entity ID."; not found in its prose, 2026-10-02: the response for that case. The 0.7.0 OpenAPI artefact defines 404 ("No link resolver entry found for this identifier.") and 400 for a path that does not match the registered scheme patterns.

The specification describes the gtr Uniform Resource Name (URN) namespace of the UN global trust register as "IANA registration pending" (see un-gtr-urn).

Committed next

  • release of UNTP version 1.0 (no date given) (undated) [maintainer or chair statement] https://untp.unece.org/docs/0.7.0/specification/IdentityResolver (opens in a new tab)

Boundary

The internal workflow of an identity resolver is not defined; the specification lists conditions a link resolver should handle consistently.
