Relevance

The charter defines vCon as a JSON container "to contain and/or reference conversational data, including call style metadata, recordings, data exchanged or presented in the conversations, conversation analysis, transcriptions, translations and annotations", so it is the IETF format for the record of a conversation.

On 2026-10-06 a participant proposed on the list to recharter the group to finish the core specification and to add an extension for "ai agent interaction record data"; the charter text he points to adds a baseline format and an "AI Agent Extension" for tool call requests and responses, model details, token usage, prompts and reasoning.

The AUDIT effort proposes to treat VCON as its record format for interaction records (see ietf-audit); a related individual draft, draft-rosenberg-cheq-00 (dated 2025-07-24, expiry date 2026-01-25), defines a signed object by which a human confirms an action proposed by an AI agent. On 2026-10-06 the author of this map asked on the list whether the extension's list could name "user instructions and approvals, and references to related records in other protocols"; no reply to that message is among the 6 list messages of 2026-10-06 and 2026-10-07 that were read.

On 2026-10-07 the editor of the core draft reported an updated editors copy with "elevation of the party_history events to the top level Events Object" and a Session concept, and that the examples are not yet updated. The editor of the core draft wrote on 2026-10-08, "After discussion in the vCon Interim WG Meeting today, this PR has been merged in to the Charter in the repo."; pull request #37 shows the merge at 15:53 UTC (merge commit 5bd8dbf, file vcon_charter.md in ietf-wg-vcon/draft-ietf-vcon-vcon-core).

This is a change to the working group's charter file in its repository; no IESG action on a new charter was found. Pull request #39, a typo fix to the charter, was reported merged on the list on 2026-10-08.
