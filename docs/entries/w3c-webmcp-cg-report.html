WebMCP (Draft Community Group Report, Web Machine Learning CG)

W3Cspecificationcontext entry

Verified 2026-11-09. Status as of 2026-11-09. All entries.

Seams: S3

Status

Draft Community Group Report, dated 9 October 2026 on the page read on 2026-10-13 (2026-09-30 on 2026-10-03), no numbered version; on 2026-10-08 PR #338, "Remove declarative API from spec", was merged (the specification now focuses on the imperative registerTool() API); the draft Agentic Web Working Group (WG) charter lists WebMCP as its normative deliverable. At TPAC, the Web Machine Learning CG meeting of 2026-10-27 recorded resolutions (draft minutes, read 2026-11-09), among them: to explore making the API "a more generic communication tool"; agreement on the ModelContextClient API shape (issue #227); "Declarative WebMCP work continues in the explainer form within this repo, advancement to spec stage will be considered once implementation experience is available"; and that general "Web Security and Privacy Guidance for Agent Implementers" belongs in a group chartered for that work.

Relevance

Draft: "The WebMCP API enables web applications to provide JavaScript-based tools to AI agents."; an editor wrote on 2026-09-25 that identity and delegation proposals "are beyond the scope of the simple WebMCP API".

Committed next
