OpenID Foundation AuthZEN Working Group (agent authorization drafts AARP and COAZ)

Independentwork-itemcontext entry

Verified 2026-10-13. Status as of 2026-10-13. All entries.

Seams: S3

Status

AARP and COAZ adopted as Working Group Drafts on 2026-06-15; to be refined through community review and interoperability testing.

Relevance

AARP covers prerequisites such as approvals, consent or attestations before a policy decision; COAZ, the profile for MCP tool authorization, maps information models into the Subject-Action-Resource-Context structure. The OpenID Foundation published a whitepaper, "Identity Management for Agentic AI" (OpenID Foundation page 2025-10-07, arXiv 2510.25819 v1 2025-10-29), on authentication and authorization for AI agents; it "outlines the resources already available for securing today's agents and presents a strategic agenda". The whitepaper names Web Bot Auth, one IETF proposal described as a "passport for agents", and the Agent Payments Protocol (AP2); it does not name UCP, ACP, x402 or TAP (text search, counts in the evidence).

Committed next

None declared in the sources read.
