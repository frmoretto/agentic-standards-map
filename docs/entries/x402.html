PR #4 of the working group, which proposes a small entry at /.well-known/x402 linking to OpenAPI documents, is open.

Relevance

The README says "x402 is an open standard for internet native payments."; the server answers 402 with a PAYMENT-REQUIRED header, the client replies with PAYMENT-SIGNATURE, and an http-message-signatures extension identifies the paying agent. The offer-and-receipt extension lets the server "cryptographically commit to the payment terms it presents in" accepts[] (the payment terms of the offer, not the commercial terms of the sale) and sign a receipt; it says "Wire shape and field placement are not considered stable". The FAQ describes the exact scheme as a push payment, "irreversible once executed". Discovery (seam S1), read 2026-10-23: in the Domain Discovery working group of the x402 Foundation (x402-foundation/wg-domain-discovery) a verifier response schema was merged on 2026-10-02 (PR #6, proposal/verifier-schema.md); PR #8, open since 2026-10-11, proposes /.well-known/x402 as a single canonical discovery path with a JSON schema, and issue #11, open since 2026-10-14, discusses the shape of that entry and its alignment with x402; in the core repository PR #2979, open since 2026-07-29, proposes DNS and .well-known records for facilitators. /.well-known/x402: not found in a GitHub code search of x402-foundation/x402 (default branch), 2026-10-23.
