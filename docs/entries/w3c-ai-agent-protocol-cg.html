W3C AI Agent Protocol Community Group

W3Cvenuecore entry

Verified 2026-11-09. Status as of 2026-11-09. All entries.

Seams: S1

Status

Active Community Group (created 2025-05-08); agent identity is DID-method-agnostic (did:wba, did:web, did:webvh) since 2026-08-13. Bi-weekly meetings; the meeting of 2026-10-07 was announced as canceled (calendar notice of 2026-10-01), and a meeting was held on 2026-10-21, whose minutes were added to the repository on 2026-10-22; the W3C group data list two chairs. Pull request #46, "Add Agent Authorization specification", opened on 2026-10-21, was open and not merged on 2026-10-23, with no comments or reviews; two ways of identifying the agent as an OAuth client were discussed (a DID as the client identifier, or the HTTPS client identifier of a Client ID Metadata Document bound to a DID), and no choice between them is recorded; commits of 2026-10-22 to the pull request move it to DID-associated Client ID Metadata Document URLs. On 2026-11-02 PR #46 is still open and not merged. The group's white paper ("Agent Network Protocol White Paper", CG-DRAFT, index.html last changed on 2026-01-14) compares MCP, A2A, ANP, Agent Connect Protocol and Agent Communication Protocol; UCP, AP2, x402 and commerce are not found in it (read 2026-11-02). The agenda of the meeting of the W3C Autonomous Agents on the Web Community Group (WebAgents) at TPAC on 2026-10-26 (Dublin, 09:00 to 12:30) includes a talk by this group's co-chairs; no minutes were found in the WebAgents repository on 2026-11-02, and the W3C minutes page for that day answers 404 on 2026-11-09. The WebAgents CG's own notes of its call of 2026-11-06, in an unmerged pull request (#135), describe the TPAC meeting as held and say that an Interaction Task Force will be organized. At the Web and AI IG meeting of 2026-10-29 this group presented a DID to OAuth bridge (draft minutes, read 2026-11-09). WebAgents, created 2023-03-20, studies Web-based multi-agent systems built on Linked Data and hypermedia, and its charter says "No specifications will be produced under the current charter."

Relevance

The protocol draft defines an Agent Discovery Service Protocol in JSON-LD, with active discovery at https://{domain}/.well-known/agent-descriptions (opens in a new tab) and an Agent Description "Information" that covers "products, or services". The use_case.html draft includes a hotel booking scenario (Personal Agent, Search Agent, hotel Service Agent) with the requirement "Agent Transactions". The agent identity draft uses a Decentralized Identifier (DID) URL as the HTTP signature keyid with RFC 9421 and RFC 9530.

Committed next

  • Topics "streaming HTTP authentication, mutual DID authentication"; joint Technical Plenary and Advisory Committee (TPAC) session with the WebAgents Community Group (CG) under discussion (undated) [maintainer or chair statement] https://lists.w3.org/Archives/Public/public-agentprotocol/2026Sep/0009.html (opens in a new tab)
