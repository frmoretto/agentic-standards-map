Agentic Commerce Protocol (ACP)

Industryspecificationcore entry

Verified 2026-11-02. Status as of 2026-10-13. All entries.

Seams: S2S3S4

Status

Specification in beta, maintained by OpenAI and Stripe; MAINTAINERS.md also lists Meta (PR #236 "ADMIN: Add Meta as TSC member", merged 2026-04-24). Last dated version 2026-04-17; on 2026-10-13 main is still at commit 7fdd78d (2026-07-17), README badge "Beta", no tag or release (not found, 2026-10-13), and the directory spec/unreleased holds the changes not yet dated (checkout, cart, delegate, feed schemas and OpenAPI files).

Relevance

The README says ACP "is an interaction model and open standard for connecting buyers, their AI agents, and businesses to complete purchases seamlessly." and covers agentic checkout and delegated payment over Representational State Transfer (REST) and an MCP binding. The seller enters through the checkout session's required links field (terms, privacy, return, shipping) and the unreleased product feed, whose optional barcode has a type (GTIN, UPC or EAN) and a value; requests carry a Signature header; the order schema has a receipt_url.

The discovery RFC says "Seller identity is established through authentication (Bearer token), which is unavailable at discovery time." The OpenAI developer documentation (developers.openai.com/commerce/specs/checkout, read 2026-10-14) is a text separate from the specification in the repository (spec/unreleased).

It says "Building with the Agentic Commerce Protocol is open to all." and "Instant Checkout in ChatGPT is currently available to approved partners." It documents a cancel call for a checkout session, which answers 405 when the session is already canceled or completed, and an order object with a list of refunds (types store_credit and original_payment); the cancellation of a checkout session is thus not the cancellation or refund of a completed order.

The page /commerce/specs/delegated-payment answered HTTP 404 on 2026-10-14.
