IEEE P3931 Agent Description, Discovery, and Registry (ADDR) Interoperability

Other standards bodieswork-itemcontext entry

Verified 2026-10-13. Status as of 2026-10-13. All entries.

Status

PAR approved 2026-03-26; "Draft Development" on the IEEE SA active PARs page of the AI standards committee read on 2026-10-13.

Relevance

The Project Authorization Request (PAR) says the standard will specify "a description model, registry mechanisms, and discovery protocols for intelligent agents operating across platforms, organizations, and ecosystems".

Committed next
