Agent2Agent (A2A) protocol, core specification

AAIFspecificationcontext entry

Verified 2026-11-09. Status as of 2026-11-09. All entries.

Seams: S1

Status

Hosted project of the Agentic AI Foundation (AAIF): AAIF announced on 2026-08-17 that A2A "is joining the Agentic AI Foundation (AAIF) as a hosted project", and the A2A blog of 2026-08-27 says it "has officially been accepted as a Growth Stage project"; latest release v1.0.1, 2026-05-28. Technical Steering Committee of nine company seats since 2026-10-20 (GOVERNANCE.md, commit 98279d6, which added Bloomberg; read 2026-11-09): Google, Microsoft, Cisco, AWS, Salesforce, ServiceNow, SAP, IBM, Bloomberg.

Relevance

The AgentCard is defined in specification/a2a.proto as "A self-describing manifest for an agent."; how cards are found is in a2a-discovery. PR #2081, merged on 2026-07-30, added section 7.6.4 to the specification: "Agents MUST NOT treat the TASK_STATE_AUTH_REQUIRED state transition, by itself, as authorization for any particular operation."; the PR description calls the state "a coordination signal, not an authorization grant".
