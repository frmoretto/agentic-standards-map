For agents and tools

The map in machine-readable form. These are plain files and standard web formats.

This site uses generic web mechanisms (JSON files, link rel=alternate, schema.org JSON-LD, a sitemap). It does not adopt any of the discovery mechanisms described in the map, so that the map does not take a side in what it maps.

Counts

The numbers of sources quoted on the site (source references, distinct URLs, primary and third-party-only URLs) are produced by tools/count_sources.py (opens in a new tab), run on the files of the repository. A source reference is one use of a URL in the field sources or in a committed_next item; a distinct URL is counted once whatever the number of uses; a URL with a fragment is a different URL. The script counts URLs and does not check that they respond.

Updates

Each entry carries its own read date (the fields verified and status_as_of). The site is regenerated from the data at each commit of the repository; the newest verification date is 2026-11-09. Update cadence: numbered versions are released on Mondays; changes verified by Friday enter the following Monday.
